# Политология — защита тем 1–2

Презентационный сайт для защиты по дисциплине Pol 2118 «Политология» (ЕНУ им. Л. Н. Гумилёва).

**Темы:** «Политология как наука и учебная дисциплина» + «Политика и её роль в жизни общества».
36 пронумерованных экранов (0–35) плюс обложка, разделители блоков и финал. 5 спикеров, ~45 минут. Кейс: политические изменения в Казахстане 2026 года.

## Управление

| Клавиша | Действие |
|---|---|
| `→` `Space` | следующий экран |
| `←` | предыдущий экран |
| `Home` / `End` | первый / последний экран |
| `M` | список всех экранов |
| `N` | текст спикера для текущего экрана |
| `F` | полноэкранный режим |
| `R` | открыть пульт в новом окне |

На телефоне и планшете — свайп влево и вправо.

## Пульт

Откройте `?remote=1` во втором окне того же браузера. Пульт показывает текущий экран,
следующий и текст спикера, кнопки «назад» и «вперёд» листают презентацию.

## Имена спикеров

Откройте `data.js`, замените значения `name` в массиве `SPEAKERS` — имена подставятся по всему сайту.

## Локальный запуск

Достаточно открыть `index.html` в браузере. Интернет нужен только для веб-шрифтов,
без него сайт работает на системных шрифтах.

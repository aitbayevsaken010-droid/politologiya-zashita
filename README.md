# Политология — защита тем 1–2

Презентационный сайт для защиты по дисциплине Pol 2118 «Политология» (ЕНУ им. Л. Н. Гумилёва).

**Темы:** «Политология как наука и учебная дисциплина» + «Политика и её роль в жизни общества».
16 пронумерованных экранов (0–15) плюс обложка, разделители блоков и финал. 5 спикеров, ~13 минут. Светлая тема. Кейс: политические изменения в Казахстане 2026 года.

## Управление

| Клавиша | Действие |
|---|---|
| `→` `Space` | следующий экран |
| `←` | предыдущий экран |
| `Home` / `End` | первый / последний экран |
| `M` | список всех экранов |
| `N` | текст спикера для текущего экрана |
| `F` | полноэкранный режим |
| `R` | открыть пульт в новом окне |

На телефоне и планшете — свайп влево и вправо.

## Пульт

Откройте `?remote=1` во втором окне того же браузера. Пульт показывает текущий экран,
следующий и текст спикера, кнопки «назад» и «вперёд» листают презентацию.

## Сценарии

На самих экранах нет имён спикеров и таймингов — это аудиторная версия. Текст спикера для текущего экрана открывается клавишей `N` (кнопки на экране нет), там же указано, сколько секунд отведено.
Все пять сценариев одной страницей для печати — `script.html`. Тот же текст в Word — `materials/Сценарий-защиты-13-минут.docx`, в Markdown — `materials/СЦЕНАРИЙ-13-минут.md`.
Полные 45-минутные версии выступлений лежат в `materials/full-version/` как справочный материал.

## Имена спикеров

Откройте `data.js`, замените значения `name` в массиве `SPEAKERS` — имена подставятся по всему сайту.

## Локальный запуск

Достаточно открыть `index.html` в браузере. Интернет нужен только для веб-шрифтов,
без него сайт работает на системных шрифтах.


## Тема 3 · История политической мысли

Отдельный дек в папке `tema3/` (`tema3/index.html`). Другой визуальный язык и другой движок: все экраны стоят в одном 3D-мире,
камера перелетает между ними (модель impress.js), клавиша `M` — карта всего пути, клик по плите — перелёт к ней.
Пять остановок: Античность → Средние века → Новое время → XIX–XX век → казахская мысль, финал — сверка с Конституцией 2026 года.

Тексты для выступающих: `tema3/script.html` (печать), `tema3/materials/Тексты-тема-3.docx`, `tema3/materials/ТЕКСТЫ-тема-3.md`.
Текст текущего экрана на самой презентации: открыть адрес с `?notes` и нажать `N`.

## Производительность

Оба дека без `filter`, `backdrop-filter` и `mix-blend-mode`; анимируются только `transform` и `opacity`.
Если ноутбук всё равно не тянет, добавьте к адресу `?lite` — отключатся декоративные анимации и тени.
Дек включает этот режим и сам, если замечает, что кадры идут дольше 25 мс.
